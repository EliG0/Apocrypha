# 📚 Apocrypha
> *"To understand the present, one must delve into the past." — Хермеус Мора*

Добро пожаловать в [**Апокриф**](https://elderscrolls.fandom.com/ru/wiki/Апокриф_(Lore))!

В мою огромную библиотеку, где души смертных листают книги в чёрных переплётах и без названий, а в воздухе, подобно дымке, витают идеи и доводы.

В здешних бесчисленных папках хранятся отголоски былых эпох, забытые скрипты, артефакты и руины древних завершеных экспериментов. Их история покоится здесь, в библиотеке забытых знаний.

> [!IMPORTANT]  
>⚠️ Коды содержат исторические ошибки, устаревшие знания, отсутствие архитектурного видения и дизайнерского вкуса.

**Загружено для самоконтроля:** чтобы помнить, в каких «яслях» я начинал свой путь, и никогда больше не писать подобное.

### 🏛 Экспонаты:

* [Jyggalag](https://github.com/EliG0/Jyggalag) — планировщик задач и заметок, родившийся из пепла Заркса. Студенческий проект\курсовая по Java для ЛГТУ.

* [Xarxes](https://github.com/EliG0/Xarxes) — пародия на Vortex (ModOrganiser) с локальным БД модификаций. Нереализованный студенческий проект\курсовая по Java для ЛГТУ.

* [**imagenerate**](https://github.com/EliG0/imagenerate) — Telegram-бот для генерации картинок с помощью с API Kandinsky. Школьный проект для Яндекс.Лицея

* **YaLicey/LisBank** — жалкая симуляция интерфейса банка на 4 буквы на PyQT. Школьный проект для Яндекс.Лицея
